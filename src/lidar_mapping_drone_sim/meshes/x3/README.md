# X3 RViz Mesh Assets

These meshes are vendored from the Gazebo Fuel model:

```text
https://fuel.gazebosim.org/1.0/OpenRobotics/models/X3 UAV/4
```

Original model metadata lists the authors as Carlos Aguero and Cole
Biesemeyer from Open Robotics. The files are used only for RViz visualization;
Gazebo still loads the X3 UAV model through the existing SDF include.

Copied files:

- `x3.dae`
- `x3.png`
- `propeller_ccw.dae`
- `propeller_cw.dae`
